# Remix of Copie of Engagez vous

Je souhaiterai une app entre akinator, un tinder de l'asso et welcome to the jungle pour faciliter l'engagement associatif en permettant aux gens de trouver facilement l'asso qui leur correspond par les valeurs, les besoins de l'asso, la manière de travailler, sur quoi l'asso est ouverte... tu vois ce que je veux dire ?
